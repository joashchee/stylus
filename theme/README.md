# The ANSIapps theme pack

The shared ANSI art every ansiapps app renders its ANSIapps theme from:
icons, app marks, splash art, spinners, and the drawn parts of buttons,
dialogs, frames and bars. A folder of `.XB` parts plus `manifest.json`,
opened in Stylus's theme mode, and rendered for each app by
`stylus-render`.

**Licensed MIT** (the repo's `LICENSE`), so every app can ship it. Each
app keeps this pack's MIT notice with the rendered files and credits it
in About.

Empty until build step 4 (the theme workshop). The rules are in
`docs/ansiapps-theme.md`, "ANSI art assets", and Diskette's
`docs/stylus-notes.md`, "The theme workshop".
